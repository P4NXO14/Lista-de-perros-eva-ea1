# Lista de perros

## Descripción

Aplicación web que muestra imágenes aleatorias de perros y permite interactuar con ellas mediante opciones como “me gusta” y “no me gusta”.

## Instalación

No requiere instalación de dependencias.

Para ejecutar el proyecto, se debe abrir el archivo `index.html` en un navegador web.

## Uso

Abrir el archivo `index.html` para visualizar la aplicación y mostrar imágenes aleatorias de perros.

## Estructura de ramas

- `main`: código estable.
- `feature/*`: nuevas funcionalidades de corta duración.
